# FlowHMR Windows v0.3.7

在顶栏打开「检查更新」，下载完成后重启 FlowHMR。也可手动导入官方便携 ZIP。

- 相机反求（实验性）。生成、预览或重算原片机位，支持 FBX、VMD、NPZ 动作与相机配对导出。
- 躯干动作优化。可开启额外一轮 FlowHMR base 生成，重新估计躯干转动，并以标准动作的脚步位置和朝向为目标。默认关闭。
- 人物接续和场景对齐（实验性）。接续同一人的多个片段，也可依次确认多人并对齐到同一场景。根据原片姿态在切点附近做局部过渡。
- 模型按需下载。「模型」面板提供 SAM 2.1（人物交叉优化，实验性）、躯干 base 和 GeoCalib 的单独下载入口。
- 导入与预览。修复远景蒙皮闪烁和切换历史任务后的空格播放，导入默认使用包内 FFmpeg。
- MCP。支持相机反求的启动、查询、停止和配对导出。

遮挡或相似衣着交叉时仍可能串轨。近景裁切和快速推拉时，可对照原片核对接缝和机位。

## 验证范围

| 项目 | 本地测试 |
| --- | --- |
| 原片相机 | 《测试4》九段共生成 2993 帧，恢复 2899 帧机位。在 30／60／120 FPS 下检查切点和源视频同步。配对 FBX 相机在 Blender 4.5.3 回读，VMD 相机关键帧与导出时间线对应。 |
| 躯干动作优化 | 108 帧固定机位样本生成通过，足底采样点相对标准动作最大位置差约 0.05 mm。此前 5 条轨迹的开关对照中，开启后的扭转幅度 P95 增大，相对原片姿态估计的平均角度偏差也增大。 |
| 跨镜头接续 | 《测试4》首段与单独生成的动作逐帧对比，切点测试覆盖近景、全身和片尾换镜。第 1456 帧应用局部过渡后，上肢最大转角跳变从 77.1° 降到 12.0°。 |
| 多人场景 | 用双人切镜片段和《D_N_A》原片验证逐个确认人物、按人物接续和场景预览。 |
| 模型管理 | 核对 SAM 2.1、躯干 base、GeoCalib 和 VGGT-Omega 的安装状态与下载入口，并模拟缺文件时的单项下载请求。 |

《测试4》第 1199 帧仍有腕部转角跳变。部分镜头机位无可用结果时，切回普通视角可继续检查动作。
