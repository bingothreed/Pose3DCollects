# FlowHMR Windows v0.3.8

在顶栏打开「检查更新」，下载完成后重启 FlowHMR。也可手动导入官方便携 ZIP。

- 相机反求（实验性）。生成、预览或重算原片机位，支持 FBX、VMD、NPZ 动作与相机配对导出。跨镜头的运动机位任务会复用生成时的逐镜头机位和人物观测，减少反求阶段的重复计算。
- 躯干动作优化。可开启额外一轮 FlowHMR base 生成，重新估计躯干转动，并以标准动作的脚步位置和朝向为目标。默认关闭。
- 人物接续和场景对齐（实验性）。接续同一人的多个片段，也可依次确认多人并对齐到同一场景。运动机位下的单人接续，会在同一镜头内补齐短时漏检的人物框，并在切点对齐人物朝向。原片姿态支持连续时，片段一起推理，减少接缝处的动作跳变和重复帧。
- 模型按需下载。「模型」面板提供 SAM 2.1（人物交叉优化，实验性）、躯干 base 和 GeoCalib 的单独下载入口。
- 导入与预览。修复远景蒙皮闪烁和切换历史任务后的空格播放，导入默认使用包内 FFmpeg。
- MCP。支持相机反求的启动、查询、停止和配对导出。

用旧视频重新生成动作，即可使用本次完整的接续与相机修复。遮挡或相似衣着交叉时仍可能串轨。近景裁切和快速推拉时，可对照原片核对接缝和机位。

## 验证范围

| 项目 | 本地测试 |
| --- | --- |
| 原片相机 | 在 RTX 5090 D 上复测《测试4》第 1199–1455 帧，257 帧相机全部可用，预览数据和 FBX、VMD、NPZ 配对导出回读通过。同配置开启躯干优化时，动作生成后的相机反求由 78.4 秒降到 5.8 秒。 |
| 跨镜头接续 | 同一片段的第 1398→1399 帧，上肢最大转角由 12.0° 降到 6.6°，并修复切点后一帧沿用后续姿势的问题。 |
| 躯干动作优化 | 在同一片段复测开启和关闭。第一镜开启时的关节投影误差较高，关闭时更接近原片。默认关闭。 |

部分镜头机位无可用结果时，切回普通视角可继续检查动作。
